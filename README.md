# Автоматизация расчета сдельной заработной платы (Excel)

## 📌 О проекте

Инструмент для автоматического расчета выработки и заработной платы сотрудников на производстве на основе реальных операционных данных. 

Файл позволяет в пару кликов рассчитать доход за конкретный день с учетом выбранного материала, количества изготовленной продукции и текущих расценок. Модель построена на базе реальных данных за год, включая фактически отработанные дни, больничные и отпускные. Оптимизация ручных расчетов с последующей сверкой с табелем во избежание ошибок человеческого фактора и прозрачного начисления зарплаты.

## 🛠️ Ключевые функции и навыки

*   **ВПР (VLOOKUP):** Динамический поиск расценок по видам материалов и операциям.
*   **Раскрывающиеся списки (Data Validation):** Пользователь может выбрать только те материалы и операции, которые есть в базе.
*   **Связанные данные:** Автоматический пересчет итоговой суммы при изменении количества продукции или выборе другого материала.
*   **Прогнозная аналитика:** Учет реального графика, больничных и отпускных для прогнозирования ожидаемой заработной платы.
